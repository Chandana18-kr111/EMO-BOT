#  EMOBOT – AI Therapy Robot for Autism

## Problem
Children with Autism Spectrum Disorder (ASD) face difficulty in emotional recognition, communication, and social interaction. Therapy is expensive and not always available.

##  Solution
EMOBOT is an AI-powered robot built using Raspberry Pi that:
- Detects emotions (Happy / Sad)
- Responds using voice interaction
- Provides therapy activities like movement, speech, and engagement
- Uses LED and servo motors for expressive feedback

## Technology
- Raspberry Pi
- Python
- SpeechRecognition + PyAudio
- eSpeak (voice output)
- OpenCV (emotion detection)
- PCA9685 (servo control)
- GPIO (LED)

## Features
- Voice interaction
- Emotion-based response
- Therapy guidance
- Real-time interaction

##  Impact
Affordable AI therapy assistant for autism support at home and schools.
